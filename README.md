# 🎮 دومیتو — سالن مینی‌گیم‌های آنلاین

**دومیتو (Domito)** یک سالن مینی‌گیم آنلاین است که بازیکن‌ها می‌توانند در اتاق‌های چندنفره جمع شوند، برای بازی موردنظرشان رأی بدهند و با دوستانشان رقابت کنند.

هدف دومیتو این است که بازی‌های کوتاه، سریع و سرگرم‌کننده را در یک محیط ساده و دوستانه کنار هم قرار دهد. 🚀

---

## ✨ امکانات

- 👤 سیستم حساب کاربری و ورود خودکار
- 🏠 ساخت و ورود به اتاق‌های بازی
- 👑 مدیریت اتاق توسط صاحب اتاق
- 🚫 قابلیت Kick کردن بازیکنان
- 🗳️ رأی‌گیری برای انتخاب بازی
- 🎮 بازی‌های چندنفره و تک‌نفره
- 🏆 ثبت آمار برد، باخت و بازی‌ها
- 🪙 سیستم سکه و پاداش
- 🛍️ فروشگاه و تم‌های قابل خرید
- 🎯 مأموریت‌ها و پاداش‌ها
- 👥 سیستم دوستان
- 💬 چت داخل اتاق
- 🟢 نمایش وضعیت آنلاین دوستان
- 🕐 نمایش آخرین حضور و آخرین ورود
- 📊 جدول امتیازات
- 📱 طراحی مناسب برای موبایل
- ⚡ اجرای مستقیم در مرورگر

---

## 🎮 بازی‌های دومیتو

دومیتو شامل مجموعه‌ای از مینی‌گیم‌های مختلف است:

| بازی | توضیح |
|---|---|
| ❓ کوییز | پاسخ سریع به سؤال‌ها |
| ⚡ سرعت واکنش | آزمایش سرعت واکنش بازیکنان |
| 🧠 حافظه | رقابت حافظه و تمرکز |
| 🔢 اسپرینت ریاضی | حل سریع محاسبات |
| 🔤 حروف به‌هم‌ریخته | پیدا کردن کلمه صحیح |
| ⌨️ سرعت تایپ | رقابت سرعت و دقت تایپ |
| 🐍 مار | بازی کلاسیک Snake |
| 🚀 دومیتو استرا | رقابت در یک میدان فضایی |
| 🔫 توپ تفنگ | نبرد در میدان بازی |

بازی‌های جدید در آینده به دومیتو اضافه خواهند شد.

---

## 🏠 اتاق بازی

بازیکنان می‌توانند یک اتاق بسازند یا با کد اتاق وارد اتاق دوستان خود شوند.

صاحب اتاق می‌تواند بازیکنان را مدیریت کند و روند شروع بازی را کنترل کند.

بازیکنان داخل اتاق می‌توانند:

- برای بازی رأی بدهند
- با یکدیگر چت کنند
- دوستان خود را دعوت کنند
- وضعیت سایر بازیکنان را مشاهده کنند
- در بازی انتخاب‌شده شرکت کنند

## 👤 حساب کاربری

دومیتو اطلاعات بازیکنان را برای حفظ پیشرفت و آمار ذخیره می‌کند.

دومیتو از ورود خودکار استفاده می‌کند تا کاربر پس از ورود اولیه، در مراجعه‌های بعدی بتواند بدون ورود دستی دوباره وارد حساب خود شود.

## 🪙 سیستم سکه

بازیکنان با بازی کردن و کسب نتیجه می‌توانند سکه دریافت کنند.

پاداش‌های فعلی:

- 🏆 برد: `+15` سکه
- 🎮 شرکت در بازی: `+5` سکه

سکه‌ها برای خرید امکانات و تم‌های فروشگاه استفاده می‌شوند.

بازیکنان می‌توانند با استفاده از سکه‌های خود تم‌های مختلف را خریداری کرده و تم موردنظرشان را فعال کنند.
