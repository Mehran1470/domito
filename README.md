# 🎮 دومیتو — سالن مینی‌گیم‌های آنلاین

**دومیتو (Domito)** یک سالن مینی‌گیم آنلاین است که بازیکن‌ها می‌توانند در اتاق‌های چندنفره جمع شوند، برای بازی موردنظرشان رأی بدهند و با دوستانشان رقابت کنند.

هدف دومیتو این است که بازی‌های کوتاه، سریع و سرگرم‌کننده را در یک محیط ساده و دوستانه کنار هم قرار دهد. 🚀
